# The $1 "what effort are you on?" (2026-10-31)

## What happened

The session was started in the home folder, on Experiential Labs DeepSeek V4.1 Flash, in full mode. Asked "what effort are you running at rn?", the model ran 84 steps over about 18 minutes: 3,238,114 input tokens, 21,728 output tokens, $1.00. Escape did not stop it.

What it did, in order:

1. Looked in `~/.config/codegoblin` and read `codegoblin.jsonc`, then grepped the whole home folder for `reasoning.?effort` and `effort` in `**/*.json*` and `**/*.md`, which walked AppData, OneDrive and every editor extension.
2. Found the fork's `codegoblin` command on PATH and assumed it was itself. It ran `codegoblin --help`, `status` and `models`, then read the fork's `cli-agent-models.json` and its logs.
3. Ran `type auth.json`, which put every stored provider key into the conversation, the provider request and the saved session.
4. Wrote ten throwaway `tmp/inspect_db*.mjs` scripts to query the fork's SQLite databases for its "own" session, then walked the process tree and the open ports.
5. Its last call was a grep with an absolute include (`C:/Users/shawn/code/CG-Next/src/**/*.ts`). Paths are matched relative to the root, so that pattern could never match, and the grep walked the whole home folder anyway. Escape aborted the turn's signal, but grep never looked at the signal.

## Why it happened

- Nothing in the prompt said which app, model or effort level was in use, so the question could not be answered without searching. All three facts were held by the app that sent the question.
- Checkpoints were off by default (`autonomy.checkpoint` unset meant never), and there was no limit on spend at all.
- Each step resends the whole conversation. Tool output was about 38k of the 44k-token context by the end, so the later steps cost the most.
- grep and glob did not watch the stop signal, had no file limit, and accepted absolute patterns that could never match.
- Nothing scrubbed stored keys from tool output. The shell already hid secret environment variables, but not a file the model printed.

## What changed

- **Facts block** (`core/session-facts.ts`), sent every turn: the app, a note that the `codegoblin`/`cg` commands are a different app, the model, the effort level (and what auto means for this model), the permission mode and the working directory. It warns when the working directory is the home folder.
- **System prompt:** size the work to the question, stop a search that has not converged after a few steps, and don't open credential stores.
- **Brakes on by default:** ask every 40 tool calls (`autonomy.checkpoint`), and again each time one prompt passes another $0.25 (`autonomy.spend`). Set either to 0 to turn it off. A malformed value keeps the default. Unpriced models (subscriptions, local) are never stopped for money.
- **Scrubbing:** every tool result, `!` command output, `/export` and `/copy` has stored key-store secrets and secret-named environment variables replaced before the model or the clipboard sees them.
- **Search:** grep and glob stop on Escape, stop after 50,000 files with a note saying so, make an absolute pattern inside the root relative, and refuse one outside it.
- **`/copy`** now copies the whole conversation as Markdown, as the fork's `/copy` did. `/copy last` copies just the latest answer. Both work while a turn is still running.

## Checked

- The same question on the same model, from the home folder: 0 tool calls, 3,155 in and 115 out, $0.0011, correct answer. GLM 5.3 Flash also used 0 tool calls.
- TUI in a PTY, started in the home folder, with a fake model that keeps grepping: Escape showed "stopped" 64 ms after the keypress, and no further request was sent. `/copy` put the Markdown on the clipboard.
- Headless web: `/copy`, `/copy last` and the usage message all work, with no console errors.

## Later the same day

Shawn's review: a system prompt should handle many situations without naming them. So the incident-specific lines came out. The facts block no longer mentions the other `codegoblin` command or tells the model how to answer questions about itself. It is a plain "Environment" list now. The system prompt was rewritten from principles found in Codex CLI, Gemini CLI and the fork's prompts; see `docs/agent-behaviour-research.md`. Reading a secret file now asks in every mode, full access included, and grep skips secret files.
